TravelGo – Responsive Travel Landing Page

TravelGo is a modern and responsive travel landing page built using HTML5 and CSS3. It is designed to provide an attractive user interface for showcasing travel services, destinations, and offers while delivering a smooth user experience across desktop and mobile devices.

 Features

- Responsive landing page design
- Sticky navigation bar
- Hero section with Call-to-Action button
- Features section
- About section
- Clean and modern UI
- Responsive layout using CSS Flexbox
- Mobile-friendly design
- Professional color palette and typography

 Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Web Design
